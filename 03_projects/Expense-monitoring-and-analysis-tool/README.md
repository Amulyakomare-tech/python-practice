# 💰 Expense Monitoring and Analysis Tool

## 📌 Description

A command-line based Python application designed to track, manage, and analyze personal expenses.
The system allows users to record transactions, view expense history, and generate insights such as monthly summaries and category-wise spending.

---

## ⚙️ Features

* Add and store expenses with date, category, and description
* View all recorded expenses in a structured format
* Generate **monthly expense summary**
* Identify **highest spending category**
* View **category-wise total expenses**
* Persistent data storage using JSON

---
